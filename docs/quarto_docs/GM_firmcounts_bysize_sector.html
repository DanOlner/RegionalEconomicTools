Greater Manchester: firm counts and percents broken down by borough, size band and broad sector

Author

Dan Olner

What’s this?

  • Business count data (via NOMIS) for Greater Manchester boroughs, broken down into four firm size bands and broad sectors (SIC sections). This latest data is for 2024.
  • Two separate plots for local units vs enterprises. See below for more on that.
  • Every data point is “percent of a borough’s total unit count”, to make them comparable across places. Hover for exact percent as well as firm count.
  • England values included for comparison.

Prep code here, code for this quarto doc here.

Enterprises vs local units

This doc has as good outline that includes the different data sources used for each. Both will include public and private organisations. Quick summary:

  • Local units are all business units including head offices, branches, factories etc. These can be located in different places (e.g. supermarket branches). Source is BRES survey data.
  • Enterprises are where HQs are located. From NOMIS: “An Enterprise is the smallest combination of legal units which has a certain degree of autonomy within an Enterprise Group.”
